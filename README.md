# AI Native 헤지펀드 — 한국 주식 PIT DB와 LLM 멀티에이전트

> 경쟁력은 AI가 아니라 데이터에서 나온다.

## 핵심 주장

1. **데이터.** 한국 재무 데이터는 정정공시가 잦고 국내 벤더는 최초값과 정정값을 섞어 단일값으로 준다. 고정 래깅으로는 풀리지 않으며, 공시 접수일·접수번호를 함께 쌓는 PIT 구조만이 답이다.
2. **에이전트 조직.** Bull·Bear 토론을 거치는 매크로 파이프라인은 학계의 표준 설계(TradingAgents 2024)와 같다.
3. **검증.** LLM이 학습한 기간의 백테스트는 미래 정보를 담고 있어 원천적으로 신뢰할 수 없다. 성과 구간 분리, 사전학습 누수 차단, 규제 검토의 세 축을 보강해야 한다.

읽는 순서 — 원고 또는 사례 분석 덱으로 전체를 본 뒤, 구현 제안 두 편(데이터베이스 → 운용 시스템)으로 넘어간다.
